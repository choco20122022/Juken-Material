# 受験の素材・作文練習

青葉総合高校の特色検査(作文)に向けた、練習用のページです。

## 素材探しの旅 (`index.html`)
- 30問に答えると、内容がブラウザ内に自動保存されます(外部には送信されません)
- 「印刷」「PDFで保存」で、白黒・インク節約のレイアウトで出力できます
- 「JSONで書き出し」「読み込み」で、バックアップと別のPCへの移動ができます

## 作文の型づくり (`sakubun.html`)
- 「主張 → 理由 → 体験 → 学び → まとめ」の5段落の型を、穴埋めで覚えます
- 3つのレベルで足場を外していきます(① 文の出だしあり / ② 見出しだけ / ③ 白紙)
- 素材探しの答えを、ヒントとして欄に入れられます
- 完成した作文を、コメント欄つきで印刷・PDF保存できます
- 型を変えたいときは、`sakubun.html` 内の `PARAS`(型の定義)を編集します

使い方: ブラウザで開くだけです。
